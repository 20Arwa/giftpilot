GiftPilot app map

GiftPilot turns a visitor’s recipient, occasion, target budget in SAR, and interests into three personalized gift ideas. The ideas are not product listings: the server validates them and builds search links to a fixed set of shopping sites.

Reference route through the code

This is a map for exploring; it does not claim a live editor walkthrough took place.

  1. In components/gift-finder-form.tsx, find submit. It runs the shared schema before sending the answers to /api/recommendations.
  2. In app/api/recommendations/route.ts, find POST. It validates again, calls Gemini once, checks the response and prevents untrusted store IDs or model-made URLs from reaching the page.
  3. In components/recommendation-results.tsx, find RecommendationResults. It renders the three ideas, target budget, safety note, and external links.

To change this, start here

  • Change recipient/occasion choices, budgets, text limits, or response types in lib/recommendation-schema.ts.
  • Change store hosts, search URL formats, or category fallback rules in lib/stores.ts.
  • Change how the AI is instructed or which model is used in lib/gemini.ts; the API key is server-only in GEMINI_API_KEY.
  • Change the gift-finder layout and states in components/gift-finder-form.tsx, and the result card appearance in components/recommendation-results.tsx.

A practice to reuse

Keep the same input contract on both sides of an API boundary: the browser checks preferencesSchema before submission, and the route checks it again. Then validate provider output separately before turning it into visible data. This project applies that pattern in lib/recommendation-schema.ts and app/api/recommendations/route.ts; it helps catch malformed or untrusted data in other apps too.

Run it again

Install dependencies with npm install, set GEMINI_API_KEY and optionally GEMINI_MODEL in the ignored local .env.local, then run npm run dev and open http://localhost:3000. The AI request needs a valid key.

Sample gift image assets are illustrative only. Recommendation cards are AI-generated ideas; verify prices, availability, shipping, and sellers on the linked shopping sites.
